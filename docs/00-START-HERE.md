## The five lanes

| Member | Owns | Demo outcome |
|---|---|---|
| M1 | Integration, shared API/client, Overview, merges | One stable build on `main` |
| M2 | Review and optional Library | Approve, edit, or reject with compliance evidence |
| M3 | Studio, Brands, Insights | Create work and show feedback learning |
| M4 | Content engine | Two distinct, brand-specific variants |
| M5 | Compliance and lessons | Absolute claims fail; corrections are remembered |

The must-ship path is:

```text
Studio -> content -> compliance -> Review -> lesson -> Insights
```

Everything else is secondary. See the team plan for the exact clock, acceptance
checks, cut order, and handoffs.
